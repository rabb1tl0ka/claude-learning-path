## Summary

- Claude can read and analyze content directly out of a PDF file, using essentially the same request shape as sending an image — the PDF is placed in the same directory as the notebook and included in the request.
- Demonstrated with a short Earth.pdf excerpt (from Wikipedia's Earth article): asked Claude how Earth's atmosphere and oceans were formed, and it correctly answered "volcanic activity and outgassing," matching a statement found at the bottom of the PDF.

## My Insights

- Treated this chapter as a small, low-friction extension of image support ("no big deal here, just read the PDF").
