## Summary
Introduces two applications built and deployed by Anthropic — Claude Code and Computer Use — framed as concrete examples of agents, meant to build intuition before the course covers what agents are and how to build one.

- **Claude Code**: a terminal-based coding assistant. A small sample project (zip file) is attached to the lecture for hands-on practice — download, extract, and open it in a code editor.
- **Computer Use**: described as a set of tools that dramatically expands Claude's capabilities.
- **Claude Code has an embedded MCP client**, meaning MCP servers can be connected to it to expand its functionality — the course planned to demonstrate this by connecting Claude Code to an MCP server.
- The module ends by transitioning into a new subchapter, "Agents and workflows," which the course treats as a distinct section from this one.
